# Configuration

| Variable                       | Meaning                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `HARNESS_ROLE`                 | `api`, `matrix` or `worker`                                                                                                                                                                                                                                                                                                                                          |
| `HOST`, `PORT`                 | listening address, `0.0.0.0:8080` by default                                                                                                                                                                                                                                                                                                                         |
| `DATABASE_URL`                 | PostgreSQL connection string of a plain role, never a superuser                                                                                                                                                                                                                                                                                                      |
| `AUTH_JWKS_URL`                | JWKS of the OIDC provider the access tokens come from                                                                                                                                                                                                                                                                                                                |
| `AUTH_ISSUER`, `AUTH_AUDIENCE` | expected `iss` and `aud` of the access tokens                                                                                                                                                                                                                                                                                                                        |
| `AUTH_ANSWER_AUDIENCES`        | other audiences, comma separated, whose tokens may answer a call that waits for its owner, as Twake Space's buttons do (for instance `twakespace`): on `POST /v1/pending-calls/{id}/approve` and `/refuse`, and on no other route; empty for none, by default                                                                                                        |
| `LOG_LEVEL`                    | pino level, `info` by default                                                                                                                                                                                                                                                                                                                                        |
| `ASSISTANT_LOCALE`             | language of the assistants' and creator's texts for an owner who chose none, `en` or `fr`                                                                                                                                                                                                                                                                            |
| `ASSISTANT_TIMEZONE`           | IANA zone of the present each turn states for an owner whose calendar no read named yet (see Time zone), and of the midnight a user's day of tokens starts at, `UTC` by default                                                                                                                                                                                      |
| `PROVISIONER_CLIENT_IDS`       | the service clients, by token subject, admitted to the provisioning API (comma separated); empty for none                                                                                                                                                                                                                                                            |
| `BROKER_CONSENT_URL`           | the token broker's consent link, the same for every user, that a request shows when the broker lacks an owner's permission, as does a reminder before it expires; an https URL, empty for none                                                                                                                                                                       |
| `DELEGATION_REMINDER_HOUR`     | hour of the worker role's daily reminder to the owners whose permission for their assistant to act for them expires within five days, `0` to `23` in `ASSISTANT_TIMEZONE`, `9` by default                                                                                                                                                                            |
| `LLM_CHECK_MODEL`              | model of the gateway that checks an answer sentence by sentence, a fast one; `LLM_MODEL` by default                                                                                                                                                                                                                                                                  |
| `LLM_DECISION_MODEL`           | decision model of the gateway, such as `nox-4b`: it tells the channel messages that arrange a meeting (see Suggestions), and what an owner's message asks for among what the catalog offers, which then holds the turn to a plan and has its answer checked (see Architecture, Turns); unset, the words sort the channels and a turn runs with every tool, as before |
| `LLM_MAX_TOKENS`               | token budget of one model call, `8192` by default; a call that ran out while thinking, with nothing written, is retried once at twice the budget, at most 32768                                                                                                                                                                                                      |
| `ADMISSION_MAX_INFLIGHT`       | turns in flight on one replica, `32` by default                                                                                                                                                                                                                                                                                                                      |
| `ADMISSION_USER_QUEUE`         | turns a user may wait for on a full replica, `2` by default, `0` for none                                                                                                                                                                                                                                                                                            |
| `ADMISSION_USER_PER_MINUTE`    | turns one user may start per minute, `10` by default                                                                                                                                                                                                                                                                                                                 |
| `ADMISSION_USER_DAILY_TOKENS`  | tokens one user may spend per day, from midnight in `ASSISTANT_TIMEZONE`, `200000` by default                                                                                                                                                                                                                                                                        |
| `ADMISSION_GLOBAL_PER_MINUTE`  | turns the whole harness may start per minute, `400` by default                                                                                                                                                                                                                                                                                                       |
| `CHAT_RESERVE`                 | the share of a user's daily tokens kept for their own words, from `0` to `1`, `0.5` by default: the turns activities wake and the briefs may spend the rest (see Admission)                                                                                                                                                                                          |
| `TURN_HISTORY_MAX_CHARS`       | characters of past conversation a turn shows the model, `24000` by default: its latest exchanges whole, always the last; the session keeps all                                                                                                                                                                                                                       |
| `TURN_MAX_TOOL_CALLS`          | tool calls one turn may make, `6` by default; past them nothing runs: the model tells the owner what it did, what remains, and that it goes on if asked                                                                                                                                                                                                              |
| `TURN_MAX_TOKENS`              | tokens one turn may spend, its prompts and answers summed, `250000` by default; once spent, the model, without tools, tells the owner what it did, what remains, and that it goes on if asked                                                                                                                                                                        |
| `TURN_STATUS_DELAY_MS`         | how long a turn may go without answering before the assistant posts a status message, which closes once the turn answered; `3000` by default, at least `1000`                                                                                                                                                                                                        |
| `TURN_EVENT_MAX_DELAY_MS`      | how long a turn an event woke, or a yes resumed, may wait to start once admission first refused it, `3600000` (an hour) by default, at least `1000`; past it, the turn is given up                                                                                                                                                                                   |
| `OWNER_DEVICE_TRUST`           | `report` by default, `enforce` only when set: whether an owner's words count only from the sessions their identity signed (see The owner's sessions)                                                                                                                                                                                                                 |
| `ACTIVITY_ENABLED`             | `true` to have the worker role listen to the `activity` exchange of RabbitMQ (see The activity exchange), `false` by default; it then needs `MATRIX_SERVER_NAME` or `MATRIX_MAIL_DOMAIN`                                                                                                                                                                             |
| `ACTIVITY_AMQP_URL`            | the AMQP URL of the broker, its vhost included, with the instance's own RabbitMQ user; needed once `ACTIVITY_ENABLED`, and secret: the chart reads it from a Secret                                                                                                                                                                                                  |
| `ACTIVITY_TYPES`               | the CloudEvent types that wake an assistant (comma separated), each exactly, never a pattern; `com.twake.tasks.task.assigned.v1` by default                                                                                                                                                                                                                          |
| `CALENDAR_ENABLED`             | `true` to have the worker role listen to Calendar's fanout of invitations on RabbitMQ (see Calendar's invitations), `false` by default; it then needs `MATRIX_SERVER_NAME` or `MATRIX_MAIL_DOMAIN`                                                                                                                                                                   |
| `CALENDAR_AMQP_URL`            | the AMQP URL of the broker, Calendar's vhost included, with the instance's own RabbitMQ user; needed once `CALENDAR_ENABLED`, and secret: the chart reads it from a Secret                                                                                                                                                                                           |
| `RABBITMQ_PREFIX`              | what the names of the queues and exchanges the instance declares on the broker start with, `twake-harness` by default: its own, so that no two instances share a queue                                                                                                                                                                                               |
| `WAKEUPS_PER_HOUR`             | times events from the broker may wake one owner's assistant in a rolling hour, whatever their source, `20` by default; past it, an event wakes them no more                                                                                                                                                                                                          |
| `WAKEUPS_RETENTION_MS`         | how long the worker role keeps a wake-up and a listening journal's activity, so that an event delivered again or replayed wakes nobody twice; `2592000000` (30 days) by default, an hour at least                                                                                                                                                                    |
| `BRIEF_ENABLED`                | `true` to have the worker role wake each owner's assistant for their morning brief, on the days and at the time they chose, and the api role give it on demand (see Morning brief), `false` by default; it then needs `WAKEUPS_RETENTION_MS` of two days at least                                                                                                    |
| `QUIET_HOURS_DEFAULT`          | the quiet hours of an owner who chose none, on the wall clock of their zone, during which their assistant posts nothing on its own: a range on the quarter hour and whole days, `20:00-08:00 saturday sunday` by default, either alone, or `none` (see Quiet hours)                                                                                                  |
| `SUGGESTIONS_ENABLED`          | `false` by default, `true` only when set: whether the assistants propose actions from the messages of channels that are not encrypted (see Suggestions); off, the listener declines its invites and leaves the rooms it is in                                                                                                                                        |
| `SUGGESTIONS_USER_LOCALPART`   | localpart of the channel listener, `twake-assistant` by default; with suggestions on, a start refuses `MATRIX_SENDER_LOCALPART` and a localpart that starts with `MATRIX_ASSISTANT_PREFIX`                                                                                                                                                                           |
| `SPACE_API_URL`                | the API of Twake Space, to which a suggestion is posted for its user (`POST {SPACE_API_URL}/notifications/suggestions`); empty for none. It must be an APISIX route, or have an egress rule                                                                                                                                                                          |
| `SPACE_API_TOKEN`              | a `tws_` API token of Twake Space with the scope `notifications:write`, sent as a bearer token; secret; needed once `SPACE_API_URL` is set                                                                                                                                                                                                                           |

`TURN_MAX_TOKENS` is meant to stay below `ADMISSION_USER_DAILY_TOKENS`: admission checks the tokens a user spent that day only when a turn starts, so once started, a turn is held by its own limit alone. The defaults leave it above, for deployments that raise the daily tokens, and a deployment that keeps `200000` a day lowers `TURN_MAX_TOKENS` too.

Migrations in `migrations/` run at start, under an advisory lock so replicas do not race.
